
Parking Assistant

Problem

In some cases, the parking assistant system in newer cars does not work properly. For example, cameras can freeze in extremely cold weather or fail in rainy conditions. Additionally, new cars sometimes have software bugs that can disable the assistant system, as seen in some Mercedes-Benz models.

Solution

As cars are getting larger and parking spaces remain limited, many older cars with tinted windows or without parking assistance also face challenges. Our Parking Slot Assistant helps drivers park safely, regardless of their vehicle type.

Idea

When a driver wants to park, a set of lights installed on the parking wall provides real-time distance feedback:

Green: distance over 1 meter
Orange: distance between 50 cm and 1 meter
Red: distance under 50 cm

The lights are visible from the side mirrors when reversing, making the system useful even for cars without rear windows.
